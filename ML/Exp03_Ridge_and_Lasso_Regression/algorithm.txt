ALGORITHM: Regularized Linear Regression (Ridge vs Lasso vs OLS)

PROGRAM OBJECTIVE:
Compare standard Ordinary Least Squares (OLS) with Ridge (L2 penalty) and Lasso (L1 penalty) regularization on the Diabetes dataset using 5-fold cross-validation.

STEP 1: LOAD & PREPROCESS DATA
    1.1. Load Scikit-Learn Diabetes dataset containing 10 physiological features.
    1.2. Separate feature matrix X (10 features) and continuous target y (disease progression).
    1.3. Split dataset into train (80%) and test (20%) subsets with random_state=42.
    1.4. Fit StandardScaler on X_train and transform both X_train and X_test.

STEP 2: HYPERPARAMETER TUNING VIA CROSS-VALIDATION
    2.1. Define logarithmic alpha search space: 50 values from 10^-3 to 10^2.
    2.2. Ridge Optimization:
         - Perform 5-fold cross-validation using RidgeCV.
         - Find optimal regularization parameter alpha_ridge.
    2.3. Lasso Optimization:
         - Perform 5-fold cross-validation using LassoCV (max_iter=10000).
         - Find optimal regularization parameter alpha_lasso.

STEP 3: MODEL TRAINING
    3.1. Fit Ordinary Linear Regression (no penalty) on scaled training data.
    3.2. Fit Ridge Regression with best alpha_ridge (minimizes sum of squared errors + lambda * ||w||_2^2).
    3.3. Fit Lasso Regression with best alpha_lasso (minimizes sum of squared errors + lambda * ||w||_1).

STEP 4: EVALUATION & COEFFICIENT SPARSITY
    4.1. For each model (Linear, Ridge, Lasso):
         a. Predict progression on scaled test data.
         b. Compute MSE, RMSE, and R^2 score.
    4.2. Compare learned feature weights (coefficients):
         - Ridge shrinks weights toward zero without forcing exact zeros.
         - Lasso drives irrelevant/redundant feature weights to exactly zero (feature selection).

STEP 5: VISUALIZATION
    5.1. Subplot 1 (Coefficients Comparison): Grouped bar chart comparing feature weights across all 10 features for Linear, Ridge, and Lasso.
    5.2. Subplot 2 (R^2 Comparison): Bar chart comparing generalization R^2 scores across the three models.
