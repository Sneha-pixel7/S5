ALGORITHM: Maximum Likelihood Estimation (MLE) vs Maximum A Posteriori (MAP)

PROGRAM OBJECTIVE:
Demonstrate the Bayesian perspective of regularization by comparing unregularized logistic regression (MLE), Gaussian prior regularization (MAP L2), and Laplace prior regularization (MAP L1).

STEP 1: DATASET PREPARATION
    1.1. Load Breast Cancer Wisconsin dataset (569 samples, 30 features).
    1.2. Split into 80% train and 20% test sets (random_state=42).
    1.3. Standardize features using StandardScaler to ensure equal regularized penalization across dimensions.

STEP 2: MAXIMUM LIKELIHOOD ESTIMATION (MLE - NO PRIOR)
    2.1. Train LogisticRegression with penalty=None (or unregularized solver='lbfgs').
    2.2. Corresponds to assuming a uniform (uninformative) prior over parameters:
         theta_MLE = argmax sum(log P(y_i | x_i; theta))
    2.3. Extract weights w_mle and evaluate test accuracy and L2 weight norm: sum(w_mle^2).

STEP 3: MAXIMUM A POSTERIORI - L2 (GAUSSIAN PRIOR)
    3.1. Train LogisticRegression with penalty='l2', C=0.1, solver='lbfgs'.
    3.2. Corresponds to a zero-mean Gaussian prior: w ~ N(0, sigma^2).
    3.3. Log-posterior optimization equivalent to minimizing cross-entropy loss + lambda * ||w||_2^2.
    3.4. Extract weights w_l2, evaluate test accuracy, and compute L2 weight norm: sum(w_l2^2).
    3.5. Observe weight shrinkage compared to MLE.

STEP 4: MAXIMUM A POSTERIORI - L1 (LAPLACE PRIOR)
    4.1. Train LogisticRegression with penalty='l1', C=0.1, solver='saga'.
    4.2. Corresponds to a zero-mean Laplace prior: P(w) proportional to exp(-|w| / b).
    4.3. Log-posterior optimization equivalent to minimizing cross-entropy loss + lambda * ||w||_1.
    4.4. Extract weights w_l1, evaluate test accuracy, and count zero-valued coefficients (sparsity).

STEP 5: EVALUATION & VISUALIZATION
    5.1. Construct a comparison table for the first 10 features showing parameter estimates for MLE, MAP L2, and MAP L1.
    5.2. Plot line chart comparing weight magnitudes across the first 15 features.
    5.3. Observe:
         - MLE produces large, unconstrained weights susceptible to overfitting.
         - MAP L2 shrinks weights smoothly toward zero.
         - MAP L1 induces true sparsity (sets unimportant feature weights exactly to 0).
