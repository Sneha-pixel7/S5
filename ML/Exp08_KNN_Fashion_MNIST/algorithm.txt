ALGORITHM: K-Nearest Neighbors (KNN) Classifier on Fashion-MNIST

PROGRAM OBJECTIVE:
Evaluate the non-parametric K-Nearest Neighbors (KNN) algorithm on Fashion-MNIST image classification across hyperparameter K values, examining the trade-off between classification accuracy and inference latency.

STEP 1: LOAD & PREPROCESS DATA
    1.1. Load Fashion-MNIST dataset: 60,000 training images and 10,000 test images (28x28 grayscale).
    1.2. Subsample a manageable subset for computational tractability:
         - Sample 5,000 training instances without replacement.
         - Sample 500 test instances without replacement.
    1.3. Flatten 2D image matrices (28x28) into 1D 784-dimensional vectors.
    1.4. Normalize pixel intensity values from [0, 255] to [0.0, 1.0] by dividing by 255.0.

STEP 2: KNN GRID SEARCH OVER K
    2.1. Define list of neighborhood sizes to evaluate: k_values = [1, 3, 5, 11].
    2.2. For each k in k_values:
         a. Initialize KNeighborsClassifier(n_neighbors=k, metric='euclidean').
         b. Record training duration: start_time = time.time(); fit model on X_train; train_time = elapsed.
            (KNN is a lazy learner: fitting simply indexes training instances into memory).
         c. Record inference latency: start_time = time.time(); predict on X_test; test_time = elapsed.
            (Prediction computes Euclidean distance to all 5,000 reference points, sorts them, and votes).
         d. Compute Test Accuracy: accuracy_score(y_test, y_pred).
         e. Compute Macro F1-Score: f1_score(y_test, y_pred, average='macro').
         f. Log (k, accuracy, f1_score, test_time) into results repository.

STEP 3: EVALUATION & ANALYSIS
    3.1. Tabulate hyperparameter performance metrics into a pandas DataFrame.
    3.2. Note the effect of K:
         - K=1 is sensitive to local outliers/noise.
         - Moderate K (e.g., K=3 or 5) improves generalization by smoothing decision boundaries.
         - Higher K may oversmooth and cross class boundaries in dense areas.
         - Inference delay scales directly with dataset size and search complexity.

STEP 4: VISUALIZATION
    4.1. Create a dual-axis line plot:
         - Primary Y-axis (blue): Test Accuracy vs K value.
         - Secondary Y-axis (red, dashed): Inference Latency (seconds) vs K value.
    4.2. Display the Pareto trade-off between accuracy and runtime efficiency.
