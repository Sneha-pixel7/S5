ALGORITHM: Support Vector Machine (SVM) Kernels with PCA on Fashion-MNIST

PROGRAM OBJECTIVE:
Apply Principal Component Analysis (PCA) for dimensionality reduction on Fashion-MNIST image data and benchmark classification performance and training latency across Linear, Polynomial, and RBF SVM kernels.

STEP 1: LOAD & PREPROCESS FASHION-MNIST
    1.1. Load Fashion-MNIST dataset: 60,000 train and 10,000 test 28x28 grayscale images across 10 apparel classes.
    1.2. Display a sample grid of 10 items representing each class label.
    1.3. Subsample a stratified subset of 6,000 images to balance computational tractability and representation.
    1.4. Flatten 2D image matrices into 784-dimensional vectors and scale pixel values to [0, 1] by dividing by 255.0.
    1.5. Split into training (80%) and testing (20%) sets with stratification (random_state=42).

STEP 2: STANDARDIZATION & DIMENSIONALITY REDUCTION (PCA)
    2.1. Standardize features using StandardScaler (zero mean, unit variance).
    2.2. Apply Principal Component Analysis (PCA):
         - Initialize PCA(n_components=50, random_state=42).
         - Fit on scaled training set and project both train and test data down from 784 dimensions to 50 principal components.
         - Log the cumulative explained variance ratio retained by the 50 components.

STEP 3: SVM KERNEL TRAINING & BENCHMARKING
    3.1. Kernel 1: Linear Kernel
         - SVC(kernel='linear', C=1.0)
         - Computes dot products in original PCA feature space: K(x, x') = x^T * x'.
         - Record start time, fit model, compute elapsed training time, predict on test data.
    3.2. Kernel 2: Polynomial Kernel
         - SVC(kernel='poly', degree=3, C=1.0, gamma='scale')
         - Maps into polynomial interaction space: K(x, x') = (gamma * x^T * x' + coef0)^d.
         - Record training time, fit model, predict on test data.
    3.3. Kernel 3: Radial Basis Function (RBF) Kernel
         - SVC(kernel='rbf', C=1.0, gamma='scale')
         - Maps into infinite-dimensional Hilbert space: K(x, x') = exp(-gamma * ||x - x'||^2).
         - Record training time, fit model, predict on test data.

STEP 4: EVALUATION & ANALYSIS
    4.1. For each kernel, evaluate:
         - Overall Accuracy
         - Macro-averaged Precision, Recall, and F1-Score
         - Total Training Time (seconds)
    4.2. Tabulate metrics in a summary DataFrame and identify the top-performing kernel (typically RBF).

STEP 5: VISUALIZATION
    5.1. Render bar chart comparing classification accuracies across Linear, Polynomial, and RBF kernels.
    5.2. Plot multi-class Confusion Matrix heatmap for the top-performing kernel with full class labels to analyze misclassifications (e.g., T-shirt vs Shirt).
