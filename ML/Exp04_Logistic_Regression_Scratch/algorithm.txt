ALGORITHM: Binary Logistic Regression from Scratch vs Scikit-Learn

PROGRAM OBJECTIVE:
Implement binary logistic regression from scratch using numpy gradient descent and compare classification accuracy, precision, recall, and F1-score with scikit-learn on the Breast Cancer dataset.

STEP 1: DATA PREPARATION
    1.1. Load Breast Cancer Wisconsin diagnostic dataset (load_breast_cancer).
    1.2. Split into training (80%) and testing (20%) sets with random_state=42.
    1.3. Standardize features using StandardScaler: fit on X_train, transform both sets.

STEP 2: LOGISTIC REGRESSION FROM SCRATCH
    2.1. Define the Sigmoid Activation function:
         sigma(z) = 1 / (1 + exp(-z))
    2.2. Training Procedure (train_lr):
         a. Get number of training instances m and features n.
         b. Prepend a bias column of 1s to X: X_b = [1, X] of shape (m, n+1).
         c. Initialize weight vector w of size (n+1) to zeros.
         d. Set learning rate lr = 0.1 and epochs = 1000.
         e. Loop for 1000 iterations:
            - Compute linear logits: z = X_b @ w
            - Compute probability predictions: p = sigma(z)
            - Compute gradient: grad = (1 / m) * (X_b.T @ (p - y))
            - Update weights: w = w - lr * grad
         f. Return learned weight vector w.
    2.3. Inference:
         - Augment test set with bias column: X_test_b = [1, X_test].
         - Compute test probabilities: p_test = sigma(X_test_b @ w).
         - Predict binary labels using threshold: y_pred_scratch = (p_test >= 0.5).astype(int).

STEP 3: BENCHMARK WITH SCIKIT-LEARN
    3.1. Instantiate LogisticRegression(max_iter=1000).
    3.2. Fit model on scaled training data (X_train_sc, y_train).
    3.3. Predict classes on scaled test data: y_pred_sk = sk_model.predict(X_test_sc).

STEP 4: EVALUATION & COMPARISON
    4.1. For both Scratch and Sklearn predictions:
         a. Compute Accuracy: (TP + TN) / Total
         b. Compute Precision: TP / (TP + FP)
         c. Compute Recall: TP / (TP + FN)
         d. Compute F1-Score: 2 * (Precision * Recall) / (Precision + Recall)
         e. Display Confusion Matrix: [[TN, FP], [FN, TP]]
    4.2. Verify that scratch gradient descent closely matches scikit-learn's optimized solver.
