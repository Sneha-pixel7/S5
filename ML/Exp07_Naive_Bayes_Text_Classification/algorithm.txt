ALGORITHM: Text Classification using Naïve Bayes (Multinomial vs Bernoulli)

PROGRAM OBJECTIVE:
Compare Multinomial Naïve Bayes (word frequency distribution) with Bernoulli Naïve Bayes (binary word occurrence) for text classification on the 20 Newsgroups corpus.

STEP 1: LOAD TEXT CORPUS
    1.1. Fetch 20 Newsgroups dataset from fetch_20newsgroups for 4 categories:
         ['sci.med', 'sci.space', 'comp.graphics', 'talk.politics.misc'].
    1.2. Remove headers, footers, and quotes to prevent classification shortcuts / metadata leakage.
    1.3. Load designated training split (train_data) and evaluation split (test_data).

STEP 2: FEATURE EXTRACTION (VECTORIZATION)
    2.1. Multinomial Vectorizer:
         - Instantiate CountVectorizer(stop_words='english', min_df=2, binary=False).
         - Fits vocabulary and transforms documents into term-frequency token count matrices (X_train_counts, X_test_counts).
    2.2. Bernoulli Vectorizer:
         - Instantiate CountVectorizer(stop_words='english', min_df=2, binary=True).
         - Fits vocabulary and transforms documents into binary indicator matrices representing word presence/absence (X_train_binary, X_test_binary).

STEP 3: MULTINOMIAL NAÏVE BAYES TRAINING
    3.1. Fit MultinomialNB(alpha=1.0) on token count matrix with additive Laplace smoothing:
         P(x_i | c) = (N_ci + alpha) / (N_c + alpha * |V|)
    3.2. Predict classes on X_test_counts and compute accuracy.

STEP 4: BERNOULLI NAÏVE BAYES TRAINING
    4.1. Fit BernoulliNB(alpha=1.0) on binary indicator matrix with Laplace smoothing:
         P(x | c) = product_i [ P(x_i=1 | c)^{x_i} * (1 - P(x_i=1 | c))^{1 - x_i} ]
    4.2. Predict classes on X_test_binary and compute accuracy.

STEP 5: EVALUATION & VISUALIZATION
    5.1. Compute Accuracy and Macro-averaged F1-Score for both models.
    5.2. Tabulate comparison summary in a DataFrame.
    5.3. Render grouped bar chart illustrating Test Accuracy and Macro F1 performance.
    5.4. Compare how word frequency weighting (Multinomial) outperforms pure binary presence (Bernoulli) on multi-topic natural text.
