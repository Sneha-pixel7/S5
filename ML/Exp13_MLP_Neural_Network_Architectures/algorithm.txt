ALGORITHM: Multi-Layer Perceptron (MLP) Architecture Exploration

PROGRAM OBJECTIVE:
Investigate the influence of hidden layer depth and width in Multi-Layer Perceptron (MLP) neural networks for binary wine quality classification on the UCI Red Wine dataset.

STEP 1: LOAD & PREPROCESS DATA
    1.1. Download UCI Red Wine Quality dataset (semicolon-delimited) via pandas.
    1.2. Plot quality score distribution histogram (scores range from 3 to 8).
    1.3. Define binary classification target 'good_quality':
         - 1 if quality >= 7 (High quality wine)
         - 0 if quality < 7 (Average/low quality wine)
    1.4. Separate 11 chemical predictor attributes from target.
    1.5. Partition into 80% train and 20% test subsets with class stratification (random_state=42).
    1.6. Apply StandardScaler to normalize all 11 physicochemical features.

STEP 2: BASELINE MLP MODEL
    2.1. Train baseline shallow MLP: MLPClassifier(hidden_layer_sizes=(8,), activation='relu', max_iter=500, random_state=42).
    2.2. Predict on test set and evaluate baseline accuracy.

STEP 3: SYSTEMATIC ARCHITECTURE EXPLORATION
    3.1. Define set of single-layer and multi-layer topologies:
         architectures = [(4,), (16,), (64,), (16, 8), (32, 16, 8)].
    3.2. For each architecture arch in architectures:
         a. Initialize MLPClassifier(hidden_layer_sizes=arch, activation='relu', max_iter=1000, random_state=42).
         b. Fit model on standardized training set (X_train_scaled, y_train).
         c. Predict classes on standardized test set (X_test_scaled).
         d. Compute Accuracy, Precision, Recall, and F1-score (with zero_division=0).
         e. Record total layer count (mlp.n_layers_) and performance metrics.
         f. Cache fitted model instances.

STEP 4: MODEL EVALUATION & SELECTION
    4.1. Compile architecture performance comparison table into a pandas DataFrame.
    4.2. Identify the best architecture maximizing test F1-score:
         best_arch = results_df.loc[results_df['F1'].idxmax(), 'Architecture']

STEP 5: VISUALIZATION
    5.1. Plot bar chart of Test Accuracy vs Hidden Layer Architecture.
    5.2. Plot training loss convergence curve (loss_curve_) across epochs for the top architecture to assess convergence and gradient descent stability.
    5.3. Display Confusion Matrix for the selected optimal network architecture.
