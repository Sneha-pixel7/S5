ALGORITHM: Comparative Analysis: Logistic Regression vs Decision Tree Classifier

PROGRAM OBJECTIVE:
Compare a linear parametric model (Logistic Regression) with a non-linear non-parametric tree model (Decision Tree) on the UCI Adult Census Income dataset to predict whether annual income exceeds $50K.

STEP 1: DATA LOAD & CLEANING
    1.1. Download UCI Adult dataset from the official UCI ML repository.
    1.2. Assign column names: age, workclass, fnlwgt, education, education-num, marital-status, occupation, relationship, race, sex, gain, loss, hours, country, income.
    1.3. Replace '?' missing value indicators with NaN and drop incomplete rows.
    1.4. Binarize target variable 'income': 1 if '>50K', 0 otherwise.

STEP 2: FEATURE ENGINEERING & PREPARATION
    2.1. Identify categorical features: workclass, education, marital-status, occupation, relationship, sex.
    2.2. Identify numerical features: age, education-num, gain, loss, hours.
    2.3. Apply one-hot dummy encoding using pd.get_dummies(..., drop_first=True) to avoid multicollinearity.
    2.4. Separate feature matrix X and target array y.
    2.5. Split into 75% training and 25% testing sets (random_state=42).

STEP 3: FEATURE SCALING (FOR LOGISTIC REGRESSION)
    3.1. Fit StandardScaler on X_train to obtain standardized zero-mean unit-variance arrays (X_train_scaled, X_test_scaled).
    3.2. Note: Logistic Regression requires scaled inputs for fast gradient convergence and proper regularization, whereas Decision Trees are invariant to monotonic feature scale transformations.

STEP 4: MODEL TRAINING
    4.1. Logistic Regression:
         - Fit LogisticRegression(max_iter=1000, random_state=42) on (X_train_scaled, y_train).
         - Predict on scaled test set: y_pred_lr = log_reg.predict(X_test_scaled).
    4.2. Decision Tree Classifier:
         - Fit DecisionTreeClassifier(max_depth=5, criterion='entropy', random_state=42) on unscaled (X_train, y_train).
         - Predict on unscaled test set: y_pred_dt = tree_clf.predict(X_test).

STEP 5: EVALUATION & COMPARATIVE MATRIX
    5.1. For both models, compute:
         a. Accuracy: Total correct predictions / total samples
         b. Precision: Correct positive predictions / total predicted positives
         c. Recall: Correct positive predictions / total actual positives
         d. F1-Score: Harmonic mean of Precision and Recall
    5.2. Assemble metrics into a comparative DataFrame matrix and print conclusions on linear vs hierarchical decision boundaries.
