ALGORITHM: Hyperparameter Grid Search for Multi-Layer Perceptron on Fashion-MNIST

PROGRAM OBJECTIVE:
Conduct systematic grid search over Stochastic Gradient Descent (SGD) hyperparameters—initial learning rate, mini-batch size, and training epochs—for a Multi-Layer Perceptron on Fashion-MNIST.

STEP 1: LOAD & PREPROCESS DATA
    1.1. Download Fashion-MNIST dataset using fetch_openml('Fashion-MNIST', version=1).
    1.2. Normalize pixel features to [0.0, 1.0] by dividing by 255.0.
    1.3. Split into 80% train and 20% test sets using stratified sampling on target classes (random_state=42).
    1.4. Extract a representative training subset of 10,000 stratified samples (X_train_sub, y_train_sub) for fast, iterative grid evaluation.

STEP 2: HYPERPARAMETER GRID DEFINITION
    2.1. Define search grid dimensions:
         - Learning Rates (lr): [0.001, 0.1]
         - Mini-Batch Sizes (bs): [32, 256]
         - Epochs (epochs): [10, 20]
    2.2. Total configurations to evaluate: 2 * 2 * 2 = 8 combinations.
    2.3. Initialize empty results registry list.

STEP 3: GRID SEARCH EXECUTION LOOP
    3.1. Iterate through nested combinations of (lr, bs, epochs):
         a. Initialize MLPClassifier:
            - hidden_layer_sizes=(128, 64)
            - activation='relu'
            - solver='sgd'
            - learning_rate_init=lr
            - batch_size=bs
            - max_iter=epochs
            - random_state=42
         b. Record execution duration: start timer, fit network on X_train_sub, stop timer.
         c. Predict labels on full test set X_test.
         d. Calculate test classification accuracy percentage: accuracy_score(y_test, y_pred) * 100.
         e. Append dictionary {'LR': lr, 'Batch': bs, 'Epochs': epochs, 'Time': elapsed_time, 'Accuracy': accuracy} to results registry.

STEP 4: TABULATION & RANKING
    4.1. Convert results registry into a structured pandas DataFrame.
    4.2. Print full summary table comparing execution time and accuracy across configurations.
    4.3. Analyze trends:
         - Higher learning rate (0.1 vs 0.001) accelerates loss descent under SGD.
         - Smaller batch sizes (32) introduce stochastic regularizing noise and faster per-epoch weight updates, but may increase training time per epoch.
         - Additional epochs generally increase test accuracy until plateau.

STEP 5: VISUALIZATION
    5.1. Generate descriptive configuration labels (e.g., 'LR:0.1|B:32|E:20').
    5.2. Plot horizontal bar chart (barh) of Test Accuracy (%) for all 8 hyperparameter configurations.
    5.3. Identify the optimal hyperparameter combination.
